# LX Remote

![认可linux.do](https://ld.xh.do/ld-badge.svg)

洛雪音乐（LX Music）桌面悬浮遥控窗：常驻桌面顶部的迷你控制面板，随时控制 LX Music 的播放。

## 功能

- **上一首 / 下一首 / 播放暂停** 按钮
- **音量滑块**（拖拽实时生效，范围 0–100）
- **进度条**：点按位置跳转 + 拖拽定位，松手才 seek
- **歌词行**：实时显示当前播放的歌词，随进度即时切换
- **歌曲名 + 歌手 + 专辑** 展示
- **简洁模式**：隐藏歌词和歌手，歌曲名缩小，布局更紧凑，窗口更矮；状态记忆（刷新/重开不丢）
- **系统托盘**：左键单击切换窗口显示/隐藏
- **设置面板（窗口式）**：独立面板，带标题栏和关闭按钮；打开时窗口自动增高，关闭后恢复
- **鼠标穿透（智能）**：仅穿透空白区域；悬停在按钮/滑块/标题栏等可交互组件上自动取消穿透，可正常点击
- **窗口置顶 / 不透明度（30–100%）** 设置
- **自动重连**：与 LX Music 的状态连接断开后自动重连

## 使用方式

### 前置条件

1. **LX Music** 设置 → 网络 → openAPI：
   - ✅ 启用 openAPI
   - 端口 `23330`（默认）
   - （局域网遥控才需要 `bindLan: true`）
2. **重启 LX Music** 使设置生效

### 启动

直接运行 `lx-remote.exe`（或从开始菜单启动）即可。窗口默认置顶显示在屏幕顶部，拖动标题栏可移动位置。

### 设置面板

点击主界面右侧的 **设置** 按钮打开，可调整：

- API 地址（默认 `http://127.0.0.1:23330`）
- 不透明度（30–100%）
- 窗口置顶开关
- 鼠标穿透开关
- 简洁模式开关
- 重连按钮

## 已知限制

- 透明 + 置顶窗口在部分旧显卡驱动下可能有合成问题
